# Промпт для Codex: фоны игровых кнопок

Настрой четыре кнопки инструментов игрового экрана Zhukodav. Используй существующую версию PixiJS и текущую архитектуру проекта. Иконки лежат в icons/ и имеют прозрачный фон: цветной подложки в них нет. Нарисуй подложки средствами PixiJS Graphics отдельно от иконок. Все параметры вынеси в единый конфиг.

Базовая сцена 1920×1080. Порядок слоёв кнопки: тень → цветная подложка с контуром → прозрачная иконка → обозначение выбранного состояния. Контейнер кнопки интерактивный; дочерняя иконка отдельно клики не обрабатывает. Надписей на кнопках нет.

Координаты в логических пикселях. Относительные координаты получай как x/1920, y/1080, w/1920, h/1080. Точные значения также находятся в layout.json.

Ширина боковой полосы примерно 15% сцены. Центральное игровое поле располагается между x=290 и x=1630. При масштабировании держи кнопки в одной системе координат со сценой.

## Рисовка

- Скруглённый прямоугольник, радиус 36–40 px.
- Контур #2D1738 толщиной 6 px, внутренний относительно заданного прямоугольника. Толщина не должна незаметно менять ширину полос.
- Плотная сливовая тень со смещением (0,6) px; у нижнего края экрана её можно ограничить маской сцены. Без размытия, свечения, стекла и реалистичного объёма.
- Основная заливка сплошная; допустим небольшой светлый блик сверху, но никаких сильных градиентов.
- UI ярче спокойного сине-серого игрового фона. Цветовые соответствия инструментам не менять.

## Иконки

Добавляй PNG отдельным спрайтом поверх фона. anchor=(0.5,0.5), положение в центре кнопки. Вписывай с сохранением пропорций: максимальная ширина 80% кнопки, максимальная высота 76%. Для каждого PNG используй равномерный масштаб min(maxWidth/textureWidth,maxHeight/textureHeight). Пустые прозрачные поля уже минимальны; повторное автоматическое обрезание не требуется.

Фон можно менять независимо от иконки. Не применяй tint подложки к контейнеру целиком: это перекрасит инструмент. Не накладывай на иконку дополнительную цветную панель. Не растягивай иконки раздельно по X/Y.

## Состояния

- default: основной цвет и тень.
- hover: на устройствах с мышью осветлить только заливку на 6–8%, без изменения размеров.
- pressed: лицевую часть вместе с иконкой сместить вниз на 4 px, тень уменьшить; hitArea оставить неподвижной.
- selected: сохранить основной цвет; добавить внутренний светлый контур 3 px и небольшую галочку в верхнем углу, чтобы выбор определялся не только цветом.
- disabled: приглушить заливку, уменьшить непрозрачность иконки до 0.45, отключить обработку нажатия. Не показывать selected для недоступной кнопки.

На pointerup, pointerupoutside и pointercancel сбрасывай pressed. Наведение должно корректно сосуществовать с selected; выход указателя не снимает выбранный инструмент.

Изучи действующую логику цветных жуков перед подключением обработчиков. Сохрани существующие правила выбора, длительности и расходования инструмента; если правило отсутствует, выдели callback для подключения, не придумывая игровую механику.

## Адаптация и проверка

Весь игровой UI находится в общей логической сцене. Масштаб s=min(viewportWidth/1920,viewportHeight/1080); сцену центрировать. Существующую обработку вертикальной ориентации сохрани. Координаты для pointer-событий переводи в локальную систему игрового контейнера средствами установленной версии PixiJS.

Проверь: четыре кнопки находятся в нужных углах; между верхней и нижней кнопкой остаётся зазор; прозрачность сетки мухобойки показывает текущую подложку; иконки не перекрашиваются при hover/selected; клики срабатывают по всей кнопке; состояние нажатия не застревает; повторное открытие игрового экрана не дублирует обработчики.

Внеси изменения и перечисли изменённые файлы, проверки и ограничения.
