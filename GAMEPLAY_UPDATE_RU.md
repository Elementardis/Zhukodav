# Игровое поле и движение к еде

Сцена собирается из `images/gameplay/` в `js/gameplay-scene.js`. Координаты — 1920×1080, равномерное вписывание в окно. Игровой прямоугольник: `(290,154,1340,926)`. При изменении окна меняется только масштаб сцены: позиции и состояние жуков не пересоздаются.

## Согласованные правила

- Красный жук — мухобойка, жёлтый — **жёлтая** ловушка, фиолетовый — дихлофос, зелёный — лента. Цвет ловушки отличается от исходного голубого в UI kit по указанию пользователя. Изображения жуков не менялись.
- Удержание Q/E/W/R и Й/У/Ц/К сохранено. На сенсорном экране отдельные указатели независимо удерживают инструменты. Недоступные инструменты не принимают нажатия.
- В каждом уровне задано `food: 'pizza'`. `js/food-config.js` определяет восемь кусочков пиццы, значит восемь жизней. Отдельный `lifeCount` удалён из уровней. Лечение возвращает кусочки, но не превышает восемь.
- `durationSeconds` и длительности уровней сохранены. `levelDurationMs()` также понимает `params.durationMs`; если длительность отсутствует, применяется явно заданный fallback 30 секунд.
- Восемь ломтиков отображают жизни: один урон убирает один кусочек, порядок 3, 4, 5, 6, 7, 8, 1, 2. Семь верхних делений показывают оставшееся время, меняются справа налево и не зависят от урона.
- `spawnZone: left/right` ограничивает вход соответствующим боковым краем и половинами верхнего/нижнего краёв. `full` использует все стороны. Направление после входа — к ближайшей границе еды.
- Все типы, включая бомбы, выбираются по `spawnWeights`. Очередь пополняется до конца времени. При занятом входе объект остаётся в очереди.
- При контакте опасный жук даёт предупреждение, затем один раз снимает жизнь. Уничтожение немедленно переводит его в `resolved`. Бомба уходит без штрафа; нажатие по ней снимает жизнь.
- Лечение, замедление, хамелеон и очистка поля сохраняют прежние игровые роли. Урон, лечение, неправильное попадание и активный инструмент отображаются тонким кольцом вокруг еды. Заморозка и хамелеон показывают убывающие цветные дуги оставшейся длительности; одновременно работающие эффекты занимают соседние кольца. Удержание цветной кнопки также подсвечивает обычных и толстых жуков этого цвета.
- Симуляция использует одно игровое время: спавн, движение, предупреждение, временные эффекты, удаление и таймер. Пауза, интро, скрытая вкладка и вертикальная ориентация останавливают его. Результат уровня проверяется после контактов; нулевое здоровье имеет приоритет над победой.

## Стартовые параметры для балансировки

В `js/food-rules.js`, объект `FOOD_RULES`:

| Параметр | Значение | Назначение |
|---|---:|---|
| `bugSize` | 100 | Размер исходного холста спрайта в логических пикселях |
| `fatSizeMultiplier` | 1.4 | Размер толстого жука |
| `tapRadiusMultiplier` | 0.58 | Радиус области нажатия относительно размера |
| `reactionMs` | 400 | Окно реакции у еды; можно переопределить через `params.foodReactionMs` |
| `entryGap` | 10 | Отступ появления за границей поля |
| `spawnSeparation` | 16 | Дополнительный промежуток между входящими жуками |
| `spawnAttempts` | 32 | Попытки найти свободный вход |
| `retrySpawnMs` | 100 | Повтор занятого входа без потери объекта |
| `simulationStepMs` | 16 | Максимальный шаг симуляции для порядка событий |

Время подхода равно `BUG_BALANCE[type].lifetime × level.params.lifetimeMultiplier` (включая множители по типу). Дополнительный коэффициент 1,8 и минимум 1200 мс удалены. Скорость вычисляется как расстояние до еды, делённое на это время. Заморозка временно замедляет движение, как раньше. Окно реакции 400 мс идёт после подхода. Длительности уровней не изменены.

Взрыв бомбы восстановлен из `images/bugs/bomb.gif`: 17 кадров по 100 мс, без смены исходного изображения. `bomb-animation.png` — прозрачный атлас этих кадров, воспроизводимый игровым временем с остановкой на паузе.

## Проверки

- `node tests/food-rules.cjs`: веса бомб, стороны периметра, ограничение половин, занятый вход, независимость от FPS, замедление, окно реакции, один штраф, отмена урона после удаления, восемь жизней из пиццы, независимая шкала времени и точное время подхода.
- `node tests/survival-rules.cjs`: таймер, пауза/интро/скрытие/ориентация, приоритет поражения, перезапуск, длительности уровней.
- `node tests/home-ui.cjs`: регрессия домашнего экрана.
- `node tests/browser-gameplay.cjs`: реальный PixiJS в отдельном headless Chrome, локальный сервер, тестовый Firebase без отправки данных; игровой ввод, мультитач, подсветка жуков, особые жуки, контакт, кадры взрыва, толстые жуки, пауза, ориентация, изменение окна, победа/поражение и локальный прогресс. Снимки сохраняются в `tests/artifacts/`.

В переданной папке нет `reference/gameplay_concept_1920x1080.png`, поэтому пиксельное сравнение с концептом недоступно. Проверены сборка из отдельных PNG и координаты layout. Отправка в настоящий Firebase не тестируется; существующие вызовы аналитики сохранены.
