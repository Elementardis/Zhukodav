# Изображения игры

Пути загрузки задаются в `game.js`, `js/home-ui.js`, `js/gameplay-scene.js`,
`js/food-config.js`, `js/result-popup.js` и `js/preloader.js`.

| Папка | Назначение |
| --- | --- |
| `backgrounds/` | Фоны игрового поля и выбора уровней |
| `bugs/` | Игровые жуки и их анимации |
| `food/pizza/` | Части пиццы и целое изображение |
| `food/dressed_herring/` | Части селёдки и целое изображение |
| `food/plate_empty.png` | Общая тарелка |
| `gameplay/tools/` | Иконки инструментов |
| `gameplay/timer/` | Рамка и сегменты шкалы времени |
| `home/` | Отдельный набор домашнего экрана |
| `ui/` | Общие элементы интерфейса |
| `ui/buttons/` | Сохранённые изображения прежних кнопок |
| `ui/loading/` | Макет и ресурсы экрана загрузки |
| `ui/results/` | Общие ресурсы окон победы и поражения |

Новые блюда размещайте в `food/<ключ_блюда>/`, а путь указывайте в
`js/food-config.js`. Правила частей описаны в `food/README.md`.
Не создавайте вторую копию блюда внутри `gameplay`.

`layout.json` и `gameplay/layout.json` — разные исходные макеты игрового
экрана; пути к изображениям в них считаются относительно `images/`.
В наборах `ui/loading` и `ui/results` пути в `layout.json` относительны
папке соответствующего набора. Прежние инструкции UI kit находятся в
`README_RU.md`; они также описывают материалы, не включённые в игру.

Проверка наличия изображений еды и игрового экрана: `node tests/food-rules.cjs`.
Проверка загрузки и запуска меню: `node tests/browser-gameplay.cjs --loading`.
