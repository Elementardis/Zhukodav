Put audio files for the game in this folder with these exact names:

- bug-click.mp3 - click on any bug
- wrong-bug-click.mp3 - wrong bug/color click
- bomb-click.mp3 - click on bomb bug
- level-music.mp3 - looping level background music
- menu-music.mp3 - looping music for screens outside levels
- victory.mp3 - victory sound
- defeat.mp3 - defeat sound
- ui-click.mp3 - UI button click

MP3 is currently wired in game.js. If you want to use another format, update AUDIO_PATHS there.
