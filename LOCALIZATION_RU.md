# Локализация игры

Названия: **Кликер: Жуки против еды** / **Bug Clicker: Food Defense**.

Язык выбирается в настройках главного экрана. Выбор сохраняется отдельно от прогресса в `bugClicker.language`. Переключение перезагружает страницу и заново создаёт интерфейс и конфигурации на одном языке. Во время уровня переключателя нет. По умолчанию используется русский. Для проверки доступны `?lang=ru` и `?lang=en`; параметр URL имеет приоритет над сохранённым выбором.

## Каталог для перевода

- `locales/ru.json` — русский оригинал; тексты воспоминаний сохранены.
- `locales/en.json` — английский перевод.
- `locales/context.json` — источник и значения переменных каждой строки.
- `locales/catalog.csv` — таблица RU/EN с контекстом, UTF-8 с BOM; открывается в редакторах таблиц.
- `js/messages.js` — сгенерированный модуль; вручную не редактировать.

После изменения JSON выполнить:

```sh
node scripts/build-locales.mjs
node tests/localization.mjs
node tests/browser-gameplay.cjs --localization
```

Сборщик проверяет одинаковые ключи и переменные, отсутствие пустых переводов и обновляет модуль и CSV. CSV предназначен для передачи переводчику; изменения из него нужно перенести в JSON, иначе следующая сборка их перезапишет. Ключи стабильны: при редактировании текста не перенумеровывать существующие записи. Новым строкам давать понятные ключи, например `settings.language`.

## Правила текста

`t(key, parameters)` возвращает строку выбранного языка. При отсутствии перевода используется русский; неизвестный ключ вызывает ошибку. `\n` — перенос строки. `{p0}`, `{p1}` и другие переменные необходимо сохранить, но можно переставлять. Их значение описано в `context.json`. Не переводить идентификаторы блюд, жуков, реплик, пути файлов, клавиши управления и ключи сохранений.

Предложения с числами вынесены целиком: не собирать перевод из отдельных слов. Формат счётчиков «Найдено X/Y кусочков» / «Pieces found: X/Y» не требует английского окончания множественного числа. Для десятичных значений используется `Intl.NumberFormat` выбранного языка.

Истории используют ключи `story.<id реплики>`. Гарри — Harry, Сесилия — Cecilia. «Селёдка под шубой» — Dressed Herring, слоёный салат; «Десерт старого друга» — An Old Friend's Dessert. На праздничных флажках используются сокращения «СДР!» / «HBD!».

## Область подключения

Локализованы игровые экраны, настройки, обучение, названия и сборка блюд, интро, 40 воспоминаний, финальная реплика, загрузка, доступные DOM aria-label и сообщения об ошибках. Строки JSON-макетов помечены `@i18n:<key>` и разрешаются загрузчиком. Тексты игровых диагностических проверок также включены в каталог. Страница внутренней аналитики `analytics.html`, комментарии разработчика, консольные технические сообщения и документация не являются интерфейсом игры и остаются вне игрового переключателя.

Растяжка, кнопки «Играть»/«Блюда» и надпись загрузки остаются PNG-картинками. Русский использует неизменённые оригиналы. Английские варианты находятся в `images/home/en/` и `images/ui/loading/assets/en/`. Реестр `js/localized-assets.js` выбирает путь по языку до загрузки ресурсов. Размеры и прозрачность вариантов совпадают с оригиналами; текст поверх картинок не рисуется. Для нового языка нужны отдельные PNG и запись в реестре. Остальные тексты используют Balsamiq Sans с поддержкой кириллицы и латиницы.

Проверка в браузере охватывает английские меню, настройки, блюда и победу на широком и узком экранах, смену на русский и сохранность прогресса. После редактирования длинных переводов отдельно проверять переносы и читаемость на телефоне.
