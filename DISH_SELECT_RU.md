# Экран блюд

Внедрён по CODEX_PROMPT_RU.md из Zhukodav_Dish_Select_Kit.zip.

Изменения: `js/dish-select.js` — UI, соответствие ID, правила доступа,
подгонка иконок по alpha-границам; `js/home-ui.js` — кнопка блюд;
`game.js` — навигация, загрузка, resize, выбор и домашнее блюдо;
`firebase.js` — поле selectedDishId в существующем progress/{uid} с merge;
`images/dishes/` — шесть исходных PNG, общий UI и layout из архива;
`tests/browser-gameplay.cjs` — сценарий --dishes.
Бирюзовая кнопка и фон домашнего экрана переиспользуются без копий.

## Данные и ограничения

- Правило открытия задаётся в `FOOD_TYPES` (`js/food-config.js`):
  `unlockLevel: X` требует победы на игровом уровне X, `0` открывает сразу,
  `null` показывает «Скоро». На закрытой карточке с числом — «После уровня X».
  Пицца доступна всегда. Уровень персонажа больше не используется.
- Жизни взяты из FOOD_TYPES.pieces. Числа из preview_states не импортированы.
- Соответствие: bundt → bundt_cake, salad → greek_salad. Остальные ID совпадают.
- Выбор хранится в localStorage.selectedDishId и синхронизируется с существующим
  документом Firebase progress/{uid}; локальный выбор при наличии имеет приоритет.
  При сетевой ошибке остаётся локальная копия. Остальной прогресс не сбрасывается.
- Геймплей использует выбранное игроком доступное блюдо. Поля food из levels.js
  удалены. Начальные/максимальные жизни равны pieces выбранного блюда; выбор
  фиксируется на начало попытки. Повтор и следующий уровень сохраняют выбор.
  Недоступный/некорректный выбор заменяется пиццей. Слои всех блюд предзагружаются.
- Необходим доступ Firestore к корневому документу progress/{uid}; реальные
  правила доступа и сетевую синхронизацию на аккаунте не проверяли.

## Проверки

Синтаксис game.js, firebase.js, js/dish-select.js; браузерный --dishes:
1920×1080, 1280×720, 844×390, шесть карточек, запрет закрытого блюда,
тестовые доступное/выбранное состояния и смена выбора, победа на заданном
уровне, возврат/повторный вход, перезагрузка и fallback некорректного ID.
Тестовые unlockLevel не сохраняются в production-конфиг.
Полный browser-gameplay.cjs проверяет регрессии игры. Firebase в тестах заменён
заглушкой. Снимки: tests/artifacts/dishes-*.png.
